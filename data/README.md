# MediSynth AI — Biomedic Dataset Directory
Contains dataset schemas, PharmGKB rulesets, DrugBank SMILES mappings, ClinVar SNP benchmarks, and sample genomic VCF files.

## Datasets Included:
1. `pharmgkb_cpic_guidelines.json` — CPIC Level 1A/1B pharmacogenomics ruleset.
2. `drugbank_smiles_structures.csv` — SMILES chemical structure strings and target binding affinities.
3. `clinvar_snp_pathogenicity.csv` — Single nucleotide polymorphism (SNP) variant annotations.
4. `fda_faers_toxicity_reports.csv` — FDA Adverse Event Reporting System post-marketing logs.
5. `sample_patient_genome.vcf` — Sample 1000 Genomes VCF file for testing variant upload.
